# Transaction 搜索与筛选实施计划

## 目标

为 Transactions 页面提供完整历史事件的关键词搜索、类型/状态/分类/日期筛选和分页浏览，同时保持 Overview 与 Reports 使用的现有 `/events` 响应不变。

## 实施范围

- 新增 `/api/events/search`，返回分页事件结果与总数。
- 关键词匹配描述、事件类型、分类、来源、外部 ID 和事件 ID。
- 日期范围按配置时区解释，起止日期均包含。
- Transactions 使用独立的分页查询状态，保留 Inspect、重分类、收据和冲销操作。
- 增加空结果、加载失败、计数和窄屏样式。

## 验证

- 后端覆盖组合筛选、关键词、分类、日期边界、分页和参数校验。
- 前端覆盖搜索、筛选、清除、分页、结果计数和空状态。
- 执行 frontend test/lint/build 与 backend pytest/ruff。

## 约束

不新增数据库迁移或第三方依赖；现有 `/events` 接口和其他页面数据流保持兼容；完成后只创建本地 commit，不推送远程。
